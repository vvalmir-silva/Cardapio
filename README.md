# DevBurguer - Cardápio Online

Projeto de cardápio digital para hamburgueria, feito com HTML, TailwindCSS e JavaScript.

## Rodando o projeto

1. Instale dependências:
   npm install

2. Rode o Tailwind em modo dev:
   npm run dev

3. Abra o `index.html` no navegador.

## Funcionalidades

- Menu de hambúrgueres e bebidas
- Carrinho de compras com modal
- Envio do pedido via WhatsApp
- Responsivo e acessível
