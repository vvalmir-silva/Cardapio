# 🖥️ Usando pgAdmin (Interface Gráfica)

## Se você instalou PostgreSQL com pgAdmin:

### 1. Abrir pgAdmin 4
# Menu Iniciar > pgAdmin 4

### 2. Conectar ao servidor
# Host: localhost
# Porta: 5432
# Usuário: postgres
# Senha: (senha que você definiu na instalação)

### 3. Criar banco de dados
# Botão direito > Create > Database
# Nome: artesanal_da_nega

### 4. Executar schema.sql
# Clique no banco artesanal_da_nega
# Tools > Query Tool
# Copie e cole o conteúdo de database/schema.sql
# Execute (F5 ou botão Play)

### 5. Verificar tabelas
# Expanda o banco > Schemas > public > Tables
# Deve ver todas as 10 tabelas criadas
